# Kaggle quick guide
1. Upload this zip as a Kaggle Dataset (Datasets -> New Dataset).
2. New Notebook -> File -> Import Notebook -> `notebooks/run_on_kaggle.ipynb`.
3. Right panel: Add Input (your dataset), Accelerator = GPU, Internet = On (needs phone verification).
4. Paste the three Google Drive links in cell 2 and run the cells in order.
Details: see the chat instructions. Models/data are NOT in this zip; cell 2 downloads them from your Drive.
